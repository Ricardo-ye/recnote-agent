# RecNote Agent · 录音笔记整理 Agent

把零散、异构、无结构的录音转写文字和资料，交给 Agent 自动归类、提炼、汇总成**可检索、可追溯、可演进**的结构化笔记库。

> 完整设计（页面结构 / 功能模块 / 数据模型 / 交互流程）见 [`docs/PRD.md`](docs/PRD.md)

---

## 快速开始

直接双击打开 `demo/index.html` 即可，无构建、无依赖、无需联网。

若要跑端到端测试，先起本地服务：

```bash
cd demo
python -m http.server 8791
node e2e.js      # 主链路 60 项断言
node e2e2.js     # 去重合并专项
```

首次打开会自动载入 3 份示例素材并跑完管线，直接能看到成库结果。

---

## 核心差异点

不是"录音转文字"，而是**保留溯源链路的自动归档**：

- **双向溯源** — 每条笔记能回溯到原始录音的哪一段；每个素材能列出产出了哪些笔记
- **人在环** — Agent 置信度不足时不给答案，而是把建议连同理由推给人工裁决
- **去重合并** — 跨素材的同主题内容自动识别相似度，建议合并而非重复建笔记
- **版本不可销毁** — 每次编辑/改判/合并/回滚都留快照，回滚本身也记一版

## Agent 管线

```
素材 → ①语义切片 → ②多信号归类 → ③结构化提炼 → ④相似度查重 → ⑤写入笔记库
```

- **①切片**：规则边界（说话人/时间戳/标点/空行）+ 语义连贯性双通道，保留 `charStart/charEnd` 溯源锚点
- **②归类**：关键词命中 0.4 + 分类质心余弦 0.35 + 来源先验 0.25，输出 Top-3 候选与置信度
- **③提炼**：TextRank 变体抽取式摘要 + 结论/待办/风险/数据四类槽位 + 领域词典优先的标签抽取
- **④查重**：余弦与 Jaccard 取大者，达阈值生成合并建议
- **⑤入库**：高置信直接建笔记，低置信降级为待确认建议

**接真实 LLM**：设置页开启 LLM、填写 OpenAI 兼容网关地址和模型即可。系统只对待人工确认的建议做分类与提炼增强；请求具有超时、JSON 结构与分类白名单校验，失败时保留本地算法结果，不会阻断摄入或绕过确认队列。API Key 仅保存于浏览器会话；生产环境应使用同源服务端网关管理凭据。

**受限 Agent 与 Memory**：`Agent.toolDefinitions()` 提供分类、草稿和记忆检索三项受限工具；模型不能直接写正式笔记。`Store.remember/recallMemories/forgetMemory` 支持会话、任务和长期偏好三层记忆，并具备来源、TTL 与删除能力。

## 技术要点

- 纯前端零依赖，`localStorage` 持久化，数据完全自持可导出
- 中文检索不依赖分词器：bigram 建索引 + BM25 变体，标题权重 ×3、标签 ×2
- 中文标签抽取用**领域词典优先 + 虚字组合过滤**，bigram 仅作兜底——避免抽出"是搜"（来自"于是搜不到"）这类跨词边界噪声
- 所有写操作强制经 `Store` 静态方法，版本记录完整率 100%
